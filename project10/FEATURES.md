# Campus Ledger

## Marks & Gradebook features added

- Class-wise Marks & Gradebook page for Academic Year 2026–27
- Select a registered class and learner from Learner Directory
- Subject marks for Tamil, English, Mathematics, Science and Social Science
- Automatic Total / 500, Percentage and Grade
- Class-wise bulk marks entry for all registered learners
- Edit/update existing marks
- Delete report card with confirmation
- Deleted marks are removed from Performance Insights
- Individual printable Student Report Card
- Search saved class results
- Marks remain after browser refresh using localStorage
- Learner deletion also removes that learner's saved academic result
